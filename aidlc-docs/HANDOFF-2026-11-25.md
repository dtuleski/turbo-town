## 4. Rules learned the hard way (keep following them)

- Prod AWS account is `342278407349`, profile `dashden-new`. Never the default profile for prod.
- Merging to `main` deploys dashden.app automatically (Vercel project `web-prod`, observed for #21, #23, #27, #30, #37).
- Changes under `packages/shared/**` or `services/{game,leaderboard,email-sender}/**` trigger `.github/workflows/deploy-lambdas.yml` (update-function-code only).
- Never `cdk deploy` the Lambda stack in prod (its Game handler differs from the live `dist/index.handler`). Database-stack changes only with `--exclusively` after a read-only `cdk diff`.
- Stacked PRs: GitHub did not retarget #19/#20 to `main`; check the base branch before merging a stack.
- Safari caches aggressively: close and reopen the tab before reporting "not visible".
